# For Oumnia ♡ — A Little Garden

A romantic, mobile-friendly website gift from Amine to Oumnia, with a bigger, fuller bouquet of eight pink peonies, falling petals, an interactive love letter, a music player, and a pony surprise.

## Test locally
1. Download and extract the ZIP.
2. Open the `little_garden_for_oumnia` folder.
3. Double-click `index.html`.
4. Try the flower button, the letter editor, the music player, and the pony surprise.

No Node.js or installation is required.

## Add your song
Copy your own audio file into this folder and name it exactly `our-song.mp3`. Open `index.html` and press the play button. If your song is an M4A file, convert it to MP3 or update the audio `src` in `index.html` to match the filename.

## Personalize the message
The main letter and headings are in `index.html`. Edit the text, save the file, and refresh the browser. The in-page letter editor is for previewing a custom extra message; for a permanent published message, edit the HTML too.

## Publish it
Upload the files `index.html`, `style.css`, `script.js` (and `our-song.mp3` if you want the song included) to a static host such as GitHub Pages or Netlify. Then share the published link with Oumnia.

Note: if you publish the MP3 with the site, anyone who has the page link may be able to access that audio file. The website uses Google Fonts when internet access is available.
